文本格式

Markdown 支持多种文本格式：

  • 粗体文字 - 使用双星号包裹
  • 斜体文字 - 使用单星号包裹
  • 删除线 - 使用波浪线包裹
  • 行内代码 - 使用反引号包裹
  • 链接文本 - 使用方括号和圆括号

列表

无序列表

  • 第一项
  • 第二项
    • 嵌套项 1
    • 嵌套项 2
  • 第三项

有序列表

  1. 第一步
  2. 第二步
  3. 第三步
    1. 子步骤 A
    2. 子步骤 B

任务列表

  • 已完成的项目
  • 另一个已完成的项目
  • 待完成的项目
  • 另一个待完成的项目

代码块

行内代码

使用 console.log('Hello World') 可以快速展示代码片段。

代码块

// JavaScript 示例
function greet(name) {
  return `Hello, ${name}! Welcome to my blog.`;
}

console.log(greet('访客'));
# Python 示例
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

print(f"斐波那契数列第 10 项: {fibonacci(10)}")
/* CSS 示例 */

  max-width: 800px;

}
