# 欢迎来到异飨客的博客 👋

这是一篇展示博客 **Markdown 渲染效果** 的示例文章。让我们一起探索各种 Markdown 语法在这个博客中的呈现效果吧！

## 文本格式

Markdown 支持多种文本格式：

- **粗体文字** - 使用双星号包裹
- *斜体文字* - 使用单星号包裹
- ~~删除线~~ - 使用波浪线包裹
- `行内代码` - 使用反引号包裹
- [链接文本](https://blog.261770.xyz) - 使用方括号和圆括号

## 列表

### 无序列表

- 第一项
- 第二项
  - 嵌套项 1
  - 嵌套项 2
- 第三项

### 有序列表

1. 第一步
2. 第二步
3. 第三步
   1. 子步骤 A
   2. 子步骤 B

### 任务列表

- [x] 已完成的项目
- [x] 另一个已完成的项目
- [ ] 待完成的项目
- [ ] 另一个待完成的项目

## 代码块

### 行内代码

使用 `console.log('Hello World')` 可以快速展示代码片段。

### 代码块

```javascript
// JavaScript 示例
function greet(name) {
  return `Hello, ${name}! Welcome to my blog.`;
}

console.log(greet('访客'));
```

```python
# Python 示例
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

print(f"斐波那契数列第 10 项: {fibonacci(10)}")
```

```css
/* CSS 示例 */
.blog-container {
  max-width: 800px;
  margin: 0 auto;
  padding: 2rem;
  line-height: 1.8;
}
```
