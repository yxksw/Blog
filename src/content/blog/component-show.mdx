## EmojiClock

现在几点了？

### 静态模式（每半小时）

<EmojiClock datetime="2024-01-01T12:00:00" /> (12:00)
<EmojiClock datetime="2024-01-01T12:30:00" /> (12:30)
<EmojiClock datetime="2024-01-01T13:00:00" /> (13:00)

### 旋转模式（每分钟）

<EmojiClock rotate datetime="2024-01-01T12:00:00" /> (12:00)
<EmojiClock rotate datetime="2024-01-01T12:05:00" /> (12:05)
<EmojiClock rotate datetime="2024-01-01T12:30:00" /> (12:30)

### 当前时间

<EmojiClock /> (当前时间)
<EmojiClock rotate /> (旋转模式)

## Key

按下键时会亮，可以通过 `@press` 配置触发事件，鼠标点击也会触发事件，博客全站搜索框的按键提示使用了这个组件。

### 纯 Code

<Key code="Escape" /> <Key code="F2" /> <Key code="Control" /> <Key code="A" /> <Key code=" " /> <Key code="Tab" /> <Key code="Enter" />

### 指定修饰符、图标、文本（macOS 自动使用图标）

<Key icon code="ArrowUp" /> <Key icon code="Alt" /> <Key icon code="Shift" /> <Key text="空格" /> <Key icon code="Tab" /> <Key icon code="Enter" />

### 组合键

<Key ctrl shift code="A" /> <Key shift alt /> <Key cmd code="K" />

### 热血组合技

上上下下左右左右BA <Key icon code="ArrowUp" /> <Key icon code="ArrowUp" /> <Key icon code="ArrowDown" /> <Key icon code="ArrowDown" /> <Key icon code="ArrowLeft" /> <Key icon code="ArrowRight" /> <Key icon code="ArrowLeft" /> <Key icon code="ArrowRight" /> <Key code="B" /> <Key code="A" />

## LinkBanner

带背景图的链接卡片，无描述时自动显示域名。

### 完整配置

<LinkBanner
  banner="https://picsum.photos/800/400"
  title="示例网站"
  description="这是一行描述，如果不提供描述会展示域名"
  link="https://example.com"
/>

### 自动提取域名

<LinkBanner
  banner="https://picsum.photos/800/400?random=2"
  title="GitHub"
  link="https://github.com"
/>

### 无背景图

<LinkBanner
  title="纯文字链接卡片"
  description="没有背景图的简洁样式"
  link="https://astro.build"
/>

## Pic

用于展示图片，支持说明文字、点击后打开灯箱缩放。

### 基础用法

<Pic
  src="https://picsum.photos/800/400?random=10"
  caption="说明文字，还支持通过 width 或 height 属性指定尺寸"
/>

### 指定尺寸

<Pic
  src="https://picsum.photos/400/300?random=11"
  caption="宽度 300px"
  width="300"
/>

### 禁用缩放

<Pic
  src="https://picsum.photos/600/300?random=12"
  caption="禁用点击缩放功能"
  zoom={false}
/>

### 仅使用 alt

<Pic
  src="https://picsum.photos/700/350?random=13"
  alt="这是一张美丽的风景图片"
/>

## Poetry

用于展示诗歌内容，支持标题、作者、落款，内容居中显示并保留换行格式。

### 完整配置

<Poetry
  title="诗有诗的标题"
  author="一名作者"
  footer="可选的落款"
>
如你所见，
我，
是一首——
诗。
</Poetry>

### 仅标题和内容

<Poetry title="静夜思">
床前明月光，
疑是地上霜。
举头望明月，
低头思故乡。
</Poetry>

### 无标题

<Poetry>
白日依山尽，
黄河入海流。
欲穷千里目，
更上一层楼。
</Poetry>

## Quote

用于展示引用内容，支持自定义图标（使用 Iconify 图标库），也支持通过 `iconHtml` 使用 Emoji 或颜文字作为图标。

### 默认图标

<Quote>
有时候，有些话，有点意思。
</Quote>

### 自定义 Iconify 图标

<Quote icon="ph:files-duotone">
令图标有所指，引用亦有中心。
</Quote>

### 使用 Emoji/颜文字作为图标

<Quote iconHtml="ヾ(•ω•`)o">
图标也可以是 Emoji 或颜文字，或者英文装饰。
</Quote>

<Quote iconHtml="💡">
灵感就像闪电，稍纵即逝，需要及时记录。
</Quote>

<Quote iconHtml="❝">
To be or not to be, that is the question.
</Quote>

## Tab

标签页组件，支持切换不同内容。将内容按顺序放入组件内，第一个子元素对应第一个标签，以此类推。

### 基础用法

<Tab tabs={['组件', '语法']}>
  <div>
    这是组件标签页的内容。
  </div>
  <div>
    这是语法标签页的内容。
  </div>
</Tab>

### 自定义默认展示标签

通过 `active` 属性设置默认展示的标签页（从1开始计数）。

<Tab tabs={['当当当', '高级交互！', '就是藏得有点深']} active={3}>
  <div>
    第一个标签页的内容。
  </div>
  <div>
    第二个标签页的内容。
  </div>
  <div>
    你找到我了吗？（默认展示第三个标签页）
  </div>
</Tab>

### 居中显示

<Tab tabs={['居中', '标签页']} center>
  <div>
    标签页整体居中显示。
  </div>
  <div>
    内容也会跟随居中。
  </div>
</Tab>

## Timeline

时间线组件，用于展示时间顺序的内容。

### 基础用法

<Timeline
  items={[
    { caption: '前天', content: '看到了小兔' },
    { caption: '昨天', content: '是小鹿' },
    { caption: '今天', content: '是你。' },
  ]}
/>

### 更多内容

<Timeline
  items={[
    { caption: '今日无事' },
    { caption: '今日依旧无事' },
    { caption: '然后——' },
    { content: '一件事<br>两件事。' },
    { content: '<em>再添一笔。</em>' },
  ]}
/>
